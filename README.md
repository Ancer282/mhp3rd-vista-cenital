# MHP3rd - Mod de Cámara Cenital (Top-Down Camera Mod)

Este es un mod para Monster Hunter Portable 3rd que sustituye la posición por defecto de la Cámara 0 por una vista completamente cenital (top-down).

---

## 📋 Requisitos Previos

Para poder aplicar y utilizar este mod en el juego, es necesario contar con el Mod Manager de kurogami2134:
* 🔗 https://gamebanana.com/tools/19380

---

## 🎮 Controles y Uso

* **Activar la cámara cenital:** Presiona la flecha hacia abajo (D-Pad Down) hasta que la cámara se coloque en posición cenital.
* **Desactivar / Volver a la vista normal:** Sube la cámara utilizando la flecha hacia arriba (D-Pad Up).

---

## 🛠️ Requisitos de Compilación

Si deseas compilar el código fuente por ti mismo, necesitarás el ejecutable armips.exe desarrollado por Kingcom.

---

## 💻 Compilación

Abre una terminal o símbolo del sistema en la carpeta del proyecto y ejecuta el comando correspondiente según la versión de tu juego:

```cmd
* Versión No HD (PSP Standard): 
armips.exe nohd.asm
```

```cmd
* Versión HD (PS3 / HD Ver.): 
armips.exe hd.asm
bash```
